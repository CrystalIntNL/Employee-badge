# Badge Brilliance

Build an employee badge and certificate generator web application. 

Key features:
1. Live Interactive Preview: A document canvas displaying the badge/certificate with high-fidelity styling (support modern light and sleek black/gold corporate executive styles with guilloche/wave patterns, clean typography, badge details card, and footer badges).
2. Badge Editor Form:
   - Organization name, department, office address, and logo uploader.
   - Employee photo uploader with preview and cropping/positioning.
   - Employee details: Full Name, Position/Title, Employment Number, Location/Home, Issue Date, Certificate ID.
   - Body description / bio paragraph.
   - Signatory block: Authorized signer name, title, and signature upload/signature canvas.
3. Templates & Customization:
   - Pre-designed layout templates (Corporate Executive, Modern Minimalist, Tech Badge).
   - Accent color picker (gold, navy, emerald, monochrome).
4. Export & Download:
   - High-resolution PDF export and PNG/print export.
   - Ready-to-print sizing presets (Letter, A4, ID Card / CR80).
5. Load demo/sample data so the preview looks immediately complete upon landing.
